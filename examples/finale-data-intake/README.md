# Synthetic interface fixture

Every record and every study trial here was generated by the regression fixtures. No drone, radar, RF, thermal sensor or participant was measured. The `real` and `human` schema paths are exercised only by unit tests; these checked-in examples remain explicitly synthetic. The revision is the originating candidate checkpoint, not a claimed trained detector revision. Replace it with the actual prediction/export code revision for a genuine intake.

From the repository root:

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/evaluate-real-data.py \
  --manifest examples/finale-data-intake/manifest.json \
  --predictions examples/finale-data-intake/predictions.jsonl \
  --output /tmp/vyuha-data-interface-report.json
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/evaluate-study.py \
  --manifest examples/finale-data-intake/study-manifest.json \
  --trials examples/finale-data-intake/study-trials.jsonl \
  --output /tmp/vyuha-study-interface-report.json
```

Expected statuses are `SYNTHETIC_INTERFACE_EVALUATED` and `SYNTHETIC_STUDY_INTERFACE_TESTED`. All numerical outputs test the interfaces only. Do not use them as presentation benchmarks or human results. This directory supplies the exact version-1 interchange schemas; see the executable validators and `docs/finale/real-world-validation/EVALUATION-RUNBOOK.md` for the gates and limitations.
