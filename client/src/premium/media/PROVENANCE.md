# Opening landscape — provenance

`blue-hour-1600.webp` and `blue-hour-960.webp` are derived from the VYUHA team's own
concept image `VYUHA-Team-Review/Round-02-Different-Worlds/Concepts/C-Blue-Hour.png`
(team design review, Round 02 "Different worlds"). The team's process notes state the
concepts were generated with a built-in image generation tool from the team's prompts.
They are illustrative artwork, not photographs of a real place, sensor data or a VYUHA
exercise. The repository owner approved shipping this image on 2026-10-15.

Edits for use as a hero background (the script is kept outside the repository):

- removed the concept's baked-in mock-up text (wordmark, navigation, headline, labels,
  button) by interpolating the surrounding sky;
- cropped the bottom band that held body copy and controls (1586 × 812 kept);
- exported as WebP (quality 92 and 90).

The interface labels the image "Illustrative landscape".
