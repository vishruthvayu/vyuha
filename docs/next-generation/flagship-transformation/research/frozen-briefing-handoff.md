# Frozen public episode briefing

Additive Flagship C/B integration on the existing next-generation source. No new engine, archive contract, session event, curriculum content, teaching efficacy claim or scoring semantics.

## Delivered API projection

The existing POST `/api/v1/learning/prepare` (new and idempotent retry) and GET `/api/v1/learning/preparations/{id}` responses now add optional `briefing`:

```
{
  version: "episode-briefing-v1",
  preparation_id, scenario_id,
  catalog_version: "learning-v1", catalog_hash, item_id,
  competency_id, mode, assistance,
  title, objective, instructions
}
```

`episode_briefing` resolves `item_for(context)`, the existing strict frozen learning context admission. `item_for` resolves `catalog_by_hash`; it never reads the current catalog to supply historical lesson prose. Exact fields form an explicit public whitelist: no scenario mix, roster, hidden truth, expected action, answer key, competency votes, profile, reflection, seed or selection/coverage data is added to this briefing.

`preparation_response` returns this projection without modifying stored preparation body/context/scenario bytes. If the frozen public prose cannot be resolved/validated, `briefing` is null; it never substitutes a current-catalog lesson. Existing authoritative attach/compile checks still decide whether a preparation can run.

Current-catalog lookup has moved below the idempotent preparation lookup. A valid historical retry/get therefore does not depend on the current curriculum pointer. Owner/request-body checks remain unchanged.

## Client contract

New `client/src/episode-briefing.ts` exports:

- `EpisodeBriefing`: readonly public contract; `instructions` is `readonly string[]`.
- `readEpisodeBriefing(preparation)`: strict version/field/scope/catalog/item/mode/assistance/prose validation, returning a fresh frozen projection or null.
- `episodeStartLabel(briefing)`: `Start Academy practice`, `Start adaptive practice` or `Start independent assessment`.

`LearningPreparation` gains only optional `briefing?: EpisodeBriefing | null`. Older preparations and restored drafts without this field remain compatible. Client fallback must remain generic, rather than fetching current-catalog prose to reinterpret an old preparation.

Parent owns App/MissionBriefing integration: use the validated title/objective/instructions and precise Start label when available. Explain unavailable frozen lesson prose when a learning preparation lacks a valid projection. Preparation itself does not start the drill.
