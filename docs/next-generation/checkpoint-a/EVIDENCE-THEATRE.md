# Evidence Reconstruction Theatre — integrated development acceptance

24 October 2026. Branch: `feature/vyuha-next-generation`. Runtime source seal and artifact hashes: [theatre-receipt.json](evidence/theatre-receipt.json). This is a bounded Level 3 replacement of the primary Ghost/Time Machine composition, not final release acceptance or a measured learning benefit.

## Actual product change

The main Review workspace now places a modeled-observation 3D canvas, cursor-time evidence dock and bounded decision rail together. A trainee can select a recorded decision, inspect EO/IR/radar availability, seek first modeled detectability, inspect the stored decision evidence, and jump to an actually observed resolution/impact where recorded. Deliberate reference-world comparison preserves the same source tick and event boundary. The existing Ghost explanation, notes/reflection, full searchable timeline, decision path, What-If and independent reference run remain reachable below.

The chapter sequence uses original review/timeline fields. Missing actions can have different review and evidence ticks; both are displayed, and unknown within-tick order remains unknown. Outcomes beyond the observed end are disabled rather than clamped into the recording. Scoring projections are never manufactured as observed impacts. Existing selected-decision seeking was already present before this work; the new contribution is the integrated investigation composition and observation/reference contract.

Modern observation input is sanitized before both Scene and Radar: mismatched/future reports and invalid optical/radar positions fail closed, missing modern reports cannot become legacy truth fallback, messages are removed, RF faults also suppress IFF cues. The cursor dock is a whitelist of modeled channel reports and trainee declarations. Canonical internal snapshot fields remain available to the existing renderer contract; its observation visibility rules still apply. Reference answers elsewhere in completed AAR already exist; the lens is an explicit presentation boundary, not an information-security boundary or blinded evaluation.

Legacy records disclose missing separate EO/IR provenance. Modeled availability is not a recording of gaze, viewport, sensor choice or noticed evidence. No authoritative engine, score, replay dispatch, schema or stored historical fixture changed.
