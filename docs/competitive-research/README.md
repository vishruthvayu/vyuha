# VYUHA: competitive research and next-generation direction

Research date: **22 October 2026**. Scope: discovery, source inspection and evaluation only. No product implementation, dependency installation, engine change or new release was performed.

**Recommendation:** develop VYUHA into an evidence-grounded learning platform with a simulation laboratory—not a larger collection of dashboard pages. Preserve the spatial workstation, deterministic browser/VR runtime and server verification. Prioritize reliable interaction and a defensible learning model before expanding AI or visual effects.

## Main discoveries

- `main` is verified at **2d90137e8116075cd1e48eadab64cb306ea12278**. The merged tree is identical to the completed unified branch at `f5cf3e85314333dce7d6273771a9e139af2c49fa`. Existing runtime evidence applies through the documented source-input hash; tests were not rerun as part of this research.
- The supplied VyomKavach service is accessible. Its 3D landing page, preparation wizard and inactive VR route were inspected live; its API schema and selected source were inspected. This is stronger evidence than a slide deck, but does not establish a completed exercise, deployed model inference, physical VR or learning efficacy.
- Several projects provide ideas worth adapting: explicit lesson progression, parameter provenance cards, sensor signal laboratories, bilingual interfaces, competency evidence and research instrumentation. Their source and runtime maturity vary greatly.
- VYUHA already has substantial depth in authoritative replay, historical compatibility, Crew attribution/isolation, offline action/Fusion recovery, What-If, evidence-only reference runs and shared browser/VR actions. Recommendations build on these capabilities.
- The clearest measured engineering gap is startup/transition consistency: the existing M1 evidence includes a retained-200-contact startup frame gap of about **1.10 seconds**, despite a 60 FPS median. No competitor's unmeasured FPS claim cancels this finding.
- The clearest strategic gap is proof of learning: neither a sophisticated Director nor synthetic classifier accuracy demonstrates better human retention or transfer. A competency/task/evidence model and a consented, controlled study would differentiate VYUHA more credibly than feature-count competition.

## First implementation sequence, after owner review

1. R01–R04: performance attribution, canonical evidence registry, competency contracts and pilot protocol.
2. R05–R09: concise Academy, assessment bank, curriculum-aware Director, calibrated assistance and active evidence collection.
3. R10–R18: causal AAR, synchronized evidence workspace, instructor authoring and deeper Crew practice.
4. R19–R30: versioned environments/sensors, lawful data ingestion, local interoperability and deployment readiness.
5. R31–R40: validated immersive interaction, optional research adapters and advanced tutoring.

No competitor source or asset has been incorporated into VYUHA. Missing licenses block reuse, not independent implementation of an interaction idea. Physical final-candidate platform/headset/network validation remains outside this desk research.
