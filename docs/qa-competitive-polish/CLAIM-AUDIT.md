# Competitive presentation claim audit

The source search is recorded in claim-search.json. New copy uses adaptive Director, persisted outcomes, deterministic Red Force patterns, server receipt, recorded application, illustrative thermal rendering and VYUHA training evidence. No learned swarm controller, sensor calibration, human efficacy, production authentication, military validation, combat-readiness or VR claim was added.

The heatmap is a within-family pooled Beta(1,1) estimate of persisted successes/failures. It is not mean trainee mastery, a controlled comparison, or an efficacy study. Rapid ID contributes only classification. Old sessions without tactic metadata retain the LEGACY label; no category is invented. Zero observations display no estimate.

Thermal palettes, static faint night grain, camera damping and translucent external-debrief terrain are presentation only. They do not change the sensor, Director, simulation, scoring, Ghost or parity contracts. Quad, friendly quad and no-RF FPV retain the same multirotor geometry; identity is not encoded through a unique ground-truth color. The selected marker is a user selection, not a classification cue.

A command is ACKNOWLEDGED only after an HTTP server receipt or a persisted command appears in polling. APPLIED requires the recorded application tick/order. A stale client has unconfirmed application, not an asserted failure to apply. Retrying uses the original command ID. A failed transport can become acknowledged/applied when polling reveals the original request.
